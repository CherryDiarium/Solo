# Solorium Ghost Theme - Agent Instructions

## Overview
This repository contains "solorium", a custom Ghost theme focused on personal blogging and imagery. It features a modern design, dark mode, custom tap highlighting for mobile interfaces, an integrated Table of Contents (tocbot), and an interactive LLM chat feature ("Ask AI").

## Directory Structure
- `assets/css/`: Theme styling (primarily `screen.css`). Includes global variables, responsive breakpoints, and custom CSS for tap highlights, navigation grids, and TOC.
- `assets/js/`: Client-side logic. Includes `toc.js` (for tocbot initialization) and `chat.js` (for the LLM chat functionality).
- `assets/built/`: Compiled output generated by `gulp`. Do not edit directly.
- `partials/`: Reusable Handlebars template chunks (e.g., icons, loop structures).
- `*.hbs`: Handlebars templates defining the site's layouts:
  - `default.hbs`: The master layout wrapper including the `<head>`, global header (`.gh-head`), and global footer.
  - `index.hbs`: The homepage layout.
  - `post.hbs`: Single post view (includes TOC structure, article content, and prev/next navigation).
  - `page-ask.hbs`: The specific page template that renders the interactive LLM chat UI.

## Related Services
- **Solorium Agent (Backend):** The backend infrastructure and logic for the "Ask AI" LLM chat feature (used in `page-ask.hbs` and `chat.js`) is managed in a separate repository: **[solorium-agent](https://github.com/CherryQuartzio/solorium-agent)**. 
- It is typically located in the same parent directory as this repo (e.g., `../solorium-agent`). If you need to make changes to the chat's server-side logic, verify its presence there.

## Agent Workflow Instructions
1. **Always bump the theme version:** Before compiling and zipping the theme for deployment, you **MUST** automatically increment the version number in `package.json`. The easiest way to do this is to run the following command before running `yarn zip`:
   ```bash
   npm version patch --no-git-tag-version
   ```
   For example, this will bump `1.1.0` to `1.1.1`.
2. **Build Process:** To compile changes and package the theme, run `yarn zip`. This triggers the gulp pipeline, minifies assets into `assets/built/`, and outputs a deployment-ready `.zip` file.
3. **Styling Best Practices:** When adjusting UI elements (like buttons and navigation) for mobile interactions, utilize `@media (pointer: coarse)` constraints to ensure hover and active states don't get stuck on touch devices. Maintain symmetric padding and respect existing flex/grid alignments.
